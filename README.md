# Data Quality Monitoring Dashboard

Built by Rounak Mishra | Data Quality Analyst | CSIR-IITR

## What This Does
Monitors 6 DQ dimensions on any CSV dataset:
- Completeness — Missing value detection
- Uniqueness — Duplicate row identification
- Consistency — Mixed types and casing
- Validity — Outlier detection via IQR
- Accuracy — Negative value checks
- Timeliness — Date currency analysis

## Tools Used
Python | Pandas | Streamlit | Plotly | Seaborn

## How to Run
pip install -r requirements.txt
streamlit run app.py
